🎨 UI 解析 - DB Migrator (.NET 8 版)

總覽 本版首頁 操作手冊 Function 對照 UI 解析 修改指南
⚠️ 注意：本版的前端檔案放在 dotnet8/wwwroot/，與 node-express 版的 public/ 內容結構相同但獨立（依您的要求不共用）。修改前端時請編輯 wwwroot 目錄下的對應檔案。

三個檔案的分工

檔案負責什麼
wwwroot/index.html結構：把畫面切成 4 個 <section class="step">
wwwroot/style.css樣式：深灰 header、白色卡片、藍色按鈕、黑底 log
wwwroot/app.js互動：事件監聽、fetch API、輪詢 job 狀態

ASP.NET Core 如何 serve 這些檔案

// Program.cs 內：
app.UseDefaultFiles();    // 找到 wwwroot/index.html 當預設首頁
app.UseStaticFiles();     // 讓 wwwroot/ 下所有檔案可以被 HTTP 取用

因此瀏覽器存取：

  • http://localhost:3001/ → wwwroot/index.html
  • http://localhost:3001/app.js → wwwroot/app.js
  • http://localhost:3001/style.css → wwwroot/style.css

JavaScript 主要事件（wwwroot/app.js）

全域狀態物件

const state = {
  type: null,        // 'mysql' / 'postgres' / 'mssql' / 'sqlite'
  connection: null,
  tables: [],
  uploadId: null,
};

主要事件鏈

卡片點擊：選 DB 類型 → 顯示連線/匯出表單 → 自動填預設 port
連線測試：POST /api/connection/test → 成功則自動 loadTables() → 失敗顯示錯誤
匯出/匯入切換：把對應 section 用 hidden 屬性互切
開始匯出：POST /api/export 拿 jobId → pollJob() 每 0.8 秒輪詢一次
匯入兩步：(1) 上傳 SQL 比對 → (2) 執行匯入

pollJob() 輪詢函式

async function pollJob(id, logSel, resultSel, onDone) {
  while (true) {
    const job = await fetch(`/api/jobs/${id}`).then(x => x.json());
    $(logSel).textContent = (job.progress || []).map(p => p.line).join('\n');
    if (job.status === 'done')  { $(resultSel).innerHTML = onDone(job); return; }
    if (job.status === 'error') { ...錯誤訊息... return; }
    await new Promise(r => setTimeout(r, 800));
  }
}
