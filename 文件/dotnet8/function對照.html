📄 Program.cs 啟動點

var builder = WebApplication.CreateBuilder(args);
builder.Services.AddSingleton<JobService>();         // DI 註冊：全 process 共用
builder.Services.AddSingleton<AdapterRegistry>();     // DI 註冊：adapter 表
builder.Services.AddControllers();                  // 啟用 MVC controller

app.UseStaticFiles();                                 // serve wwwroot

📄 Services/JobService.cs 記憶體型 Job Tracker

類別 / Method說明
Job (POCO)欄位：Id, Kind, Status, Progress, Result, Error, CreatedAt
JobProgress單一進度項：T (timestamp) + Line (文字)
JobService.Create(kind)產 GUID、建 Job 物件、放進 ConcurrentDictionary，回傳
JobService.Get(id)找不到回 null（用 TryGetValue）
JobService.Append(id, line)把一行進度加進 Progress；超過 200 筆自動丟最舊；用 lock 保護
JobService.SetStatus(id, status, patch)更新 status，並可選擇用 Action<Job> 修改其他欄位（result/error）
✨ ConcurrentDictionary 是執行緒安全的，配合 lock 保護 Progress 串列，多個 background task 同時寫不會出問題。
⚠️ 沒有 expire 機制（不像 node 版有 setInterval 清舊 job）— 若需要要自己加 BackgroundService。

📄 Adapters/IDatabaseAdapter.cs Adapter 介面

public interface IDatabaseAdapter
{
    string Type { get; }
    Task<(bool, string, string?)> TestConnectionAsync(DbConnectionInfo conn);
    Task<List<TableInfo>> ListTablesAsync(DbConnectionInfo conn);
    Task DumpAsync(DbConnectionInfo conn, ExportOptions options, string outFilePath, Action<string>? onProgress, CancellationToken ct);
    Task RestoreAsync(DbConnectionInfo conn, string sqlFilePath, Action<string>? onProgress, CancellationToken ct);
    List<string> ParseTableNamesFromDump(string sqlFilePath);
}
這是合約 — 加新 DB 時的 class 必須實作這 6 個成員。

        {

            ["postgres"] = new PostgresAdapter(),
            ["mssql"]    = new MsSqlAdapter(),
            ["sqlite"]   = new SqliteAdapter(),
        };
    }

    public IDatabaseAdapter Get(string type) { ... }   // 找不到丟 InvalidOperationException
}

📄 Adapters/SqlHelpers.cs 共用工具

Method用途
Bracket(name)用 [ ] 跳脫 identifier（T-SQL 風格）
DoubleQuote(name)用雙引號跳脫（PostgreSQL / SQLite）
Backtick(name)用反引號跳脫（MySQL）
EscapeAnsi(s)ANSI 字串：'a''b'
EscapeNPrefix(s)SQL Server 字串：N'...'（支援 unicode）
EscapeMySql(s)MySQL 字串：含 \n \r \\ \' \" 等跳脫
FormatOptions 類別把不同 DB 的格式差異打包：EscapeString、FormatBinary、BoolAs01
FormatValue(v, opts)把 .NET 任意型別轉成 SQL 字面值（涵蓋 bool / 數字 / DateTime / Guid / byte[] / string / DBNull）
SplitSqlStatements(sql, q)切句迭代器（IEnumerable）：處理注釋、字串內分號等
SplitMsSqlBatches(text)MSSQL 特有：按 GO 行分批
ParseTableNamesFromDump(path, q)regex 抓 CREATE TABLE 後的 table 名

📄 Adapters/MySqlAdapter.cs MySQL

Method說明
BuildConnString(c, allowMultiple)用 MySqlConnectionStringBuilder 組連線字串。restore 時要開 AllowUserVariables
TestConnectionAsync跑 SELECT VERSION()
ListTablesAsync查 information_schema.TABLES
EscapeIdent / EscapeString / FormatValueMySQL 特有的字串/識別字處理（含 MySQL 跳脫如 \n \r \\）
DumpTableSchemaAsync用 SHOW CREATE TABLE 拿到 DDL 直接寫進去
DumpTableDataAsync用 SequentialAccess reader 串流；每 500 筆或 0.5MB flush 一批 INSERT
DumpAsync主入口；schema 與 data 用不同 connection（避免 reader 衝突）
RestoreAsync讀整個檔，用 SplitSqlStatements 切句，逐句執行
SplitSqlStatements (private)處理 MySQL 三種引號（' " `）的注釋與字串
ParseTableNamesFromDumpregex 抓 CREATE TABLE `xxx`

📄 Adapters/PostgresAdapter.cs PostgreSQL

Method說明
ConnString(c)用 NpgsqlConnectionStringBuilder 組
TestConnectionAsyncSELECT version()
ListTablesAsync查 information_schema.tables（排除 pg_catalog / information_schema）；用 reltuples 估算筆數
GetTableDDLAsync自己組 CREATE TABLE：查 information_schema.columns 與 pg_index 的 PK，逐欄串成 DDL
DumpTableDataAsync用 NpgsqlDataReader + SequentialAccess 串流
DumpAsync / RestoreAsync同 MySQL 概念，但 restore 必須逐句執行（PG 不支援 multipleStatements）

📄 Adapters/MsSqlAdapter.cs SQL Server

Method說明
ConnString(c)用 SqlConnectionStringBuilder；Host 用 host,port 寫法
ListTablesAsync查 sys.tables join sys.schemas（回 schema.name 格式）
GetTableDDLAsync查 sys.columns + sys.types + sys.indexes 組 DDL；含 IDENTITY 與 default constraint 處理
DumpTableDataAsync用 SqlDataReader.SequentialAccess
RestoreAsync用 SplitMsSqlBatches 按 GO 切，每批用 SqlCommand 執行

📄 Adapters/SqliteAdapter.cs SQLite

Method說明
PickPath(c)從 Path / Database / Host 三選一拿檔案位置
ConnString(c, readOnly)用 SqliteConnectionStringBuilder；指定 Mode
ListTablesAsync查 sqlite_master
DumpAsync用 sqlite_master.sql 直接拿原始 DDL；資料用 reader iterate；會同時匯出 indexes
RestoreAsync包在自己的 BEGIN/COMMIT 內，逐句執行；遇到檔案內的 BEGIN/COMMIT 自動跳過避免衝突
