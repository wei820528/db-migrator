📁 重寫 Services/JobService.cs

把 ConcurrentDictionary 換成 SQLite 表，重啟 service 後 job 狀態還在。

public class JobService
{
    private readonly string _connStr = "Data Source=jobs.db";

    public JobService()
    {
        using var c = new SqliteConnection(_connStr);
        c.Open();
        using var cmd = new SqliteCommand(
          @"CREATE TABLE IF NOT EXISTS jobs(id TEXT PRIMARY KEY, kind TEXT, status TEXT, data TEXT)", c);
        cmd.ExecuteNonQuery();
    }

    public Job Create(string kind) { // INSERT into jobs ... }
    public Job? Get(string id)   { // SELECT * FROM jobs WHERE id=@id }
    ...
}
⚠️ 同時需要 lock 或 transaction 避免並發寫衝突。

🔵 場景 6：自動清理過期暫存檔（用 BackgroundService）

📁 新建 Services/CleanupService.cs
public class CleanupService : BackgroundService
{
    protected override async Task ExecuteAsync(CancellationToken stoppingToken)
    {
        var tmp = Path.Combine(AppContext.BaseDirectory, "tmp");
        while (!stoppingToken.IsCancellationRequested)
        {
            var cutoff = DateTime.UtcNow.AddHours(-24);
            foreach (var dir in Directory.GetDirectories(tmp))
            {
                try {
                    if (Directory.GetCreationTimeUtc(dir) < cutoff)
                        Directory.Delete(dir, true);
                } catch { }
            }
            await Task.Delay(TimeSpan.FromHours(1), stoppingToken);
        }
    }
}
📁 Program.cs 註冊
builder.Services.AddHostedService<CleanupService>();

🔵 場景 8：把進度改成 Server-Sent Events（取代 polling）

📁 新增 Controllers/JobsController.cs 多一個 endpoint
[HttpGet("{id}/stream")]
public async Task Stream(string id, CancellationToken ct)
{
    Response.Headers.Add("Content-Type", "text/event-stream");
    int lastSent = 0;
    while (!ct.IsCancellationRequested)
    {
        var j = _jobs.Get(id);
        if (j == null) break;
        for (int i = lastSent; i < j.Progress.Count; i++)
            await Response.WriteAsync($"data: {j.Progress[i].Line}\n\n", ct);
        lastSent = j.Progress.Count;
        if (j.Status == "done" || j.Status == "error") break;
        await Task.Delay(300, ct);
    }
}
📁 wwwroot/app.js 用 EventSource 取代 fetch
const es = new EventSource(`/api/jobs/${id}/stream`);
es.onmessage = (e) => {
  $('#exp-log').textContent += '\n' + e.data;
};

🔵 場景 9：在資料表清單顯示實際筆數（覆蓋估計值）

📁 Adapters/MySqlAdapter.cs 第 42 行 ListTablesAsync
public async Task<List<TableInfo>> ListTablesAsync(DbConnectionInfo conn)
{
    var list = new List<TableInfo>();
    await using var c = new MySqlConnection(BuildConnString(conn));
    await c.OpenAsync();
    await using var cmd = new MySqlCommand(
      "SELECT TABLE_NAME FROM information_schema.TABLES WHERE TABLE_SCHEMA = @db", c);
    cmd.Parameters.AddWithValue("@db", conn.Database);
    var names = new List<string>();
    await using (var rd = await cmd.ExecuteReaderAsync())
        while (await rd.ReadAsync()) names.Add(rd.GetString(0));

    // 對每張表跑 COUNT(*)（大表會慢，慎用）
    foreach (var n in names)
    {
        await using var cnt = new MySqlCommand($"SELECT COUNT(*) FROM `{n}`", c);
        long total = Convert.ToInt64(await cnt.ExecuteScalarAsync());
        list.Add(new TableInfo { Name = n, RowEstimate = total });
    }
    return list;
}

🔵 場景 10：發佈成單一執行檔（給沒裝 .NET 的機器跑）

dotnet publish -c Release -r win-x64 --self-contained true ^
   -p:PublishSingleFile=true ^
   -p:IncludeNativeLibrariesForSelfExtract=true ^
   -o C:\Deploy\dbmigrator

產生的 C:\Deploy\dbmigrator\DbMigrator.Web.exe 可以直接拷到任何 Windows 機器（不用裝 .NET），雙擊執行即可。

⚠️ wwwroot 與 appsettings.json 會一併輸出到同個資料夾，部署時要整個 publish 目錄一起搬。

📋 修改後檢核清單

  1. 修改 C# code 後 Visual Studio 會自動重 build；用 CLI 跑就要重新 dotnet run
  2. 修改 wwwroot/ 內 HTML/JS/CSS 不用重啟，瀏覽器 Ctrl+F5 強制重新整理即可
  3. F12 開 DevTools 看 Network → 看 API request/response 對不對
  4. VS 用 Debugger 可以在 Controller 與 Adapter 內下中斷點
  5. 檢查 tmp/ 內檔案是否有殘留（特別是改完後）
