🚀 第一次啟動

1確認 .NET 8 SDK 已安裝

dotnet --list-sdks

清單裡要有 8.0.xxx。沒有的話到 dotnet.microsoft.com 下載 .NET 8 SDK。

2還原 NuGet 套件（第一次才需要）

cd F:\匯出資料庫的bat\dotnet8
dotnet restore

會自動下載 MySqlConnector、Npgsql、SqlClient、Sqlite 等套件。

3啟動服務

dotnet run

看到下面類似訊息表示成功：

info: Microsoft.Hosting.Lifetime[14]
      Now listening on: http://localhost:3001
info: Microsoft.Hosting.Lifetime[0]
      Application started. Press Ctrl+C to shut down.

用瀏覽器打開 http://localhost:3001 即可開始使用。

💡 也可以用 Visual Studio 開 DbMigrator.sln，按 F5 啟動並自帶 debugger。

▲ 第 2 步：SQL Server 連線測試成功
SQL Server 特殊注意：
  • 本地常用 instance 名稱（SQLEXPRESS）— 目前 Host 欄位不支援 localhost\SQLEXPRESS 寫法。

🛑 停止服務

在跑 dotnet run 的視窗按 Ctrl + C 即可。
若用 Visual Studio 啟動，點工具列「停止」按鈕（紅色方框）。

📦 Production 發佈

當你要部署到正式環境，建議用 self-contained publish：

dotnet publish -c Release -r win-x64 --self-contained true -o publish

產生的 publish/ 資料夾包含 .NET runtime，可直接複製到目標機器執行 DbMigrator.Web.exe，不需要安裝 .NET。

🆘 疑難排解

症狀可能原因 / 解法
The SDK 'Microsoft.NET.Sdk.Web' specified could not be found沒裝 .NET 8 SDK（只裝了 runtime）
port 3001 已被佔用改 appsettings.json 的 Kestrel.Endpoints.Http.Url
前端打開但 API 都失敗F12 看 Network 是否真的打到 3001；可能瀏覽器快取了 3000
SQL Server 連線報 SSL 錯誤已預設 trustServerCertificate=true，若仍失敗確認 SQL Server 有開 TCP/IP
