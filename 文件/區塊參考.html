SQL adapter 實作 5 個方法：testConnection、listTables、dump、restore、parseTableNamesFromDump。 NoSQL adapter（mongo / redis）多實作一個 filterDumpByTables（自家格式過濾；SQL 系列 fallback 到 filterSqlByTables）。 Mongo dump = JSONL events（header / collection / insert）+ EJSON canonical 保留 BSON 型別；Redis dump = redis-cli 風格 command 序列。 兩個 adapter 的 Node 與 .NET 格式 byte-compatible，可互相 restore。
