⚠ 卡關 / 風險紀錄

項目風險應對
SQLite 規模上限 License DB 超過 10000 筆可能效能下滑 到時候遷移到 PostgreSQL
IP 白名單對 NAT 客戶 公司用單一出口 IP 沒問題；行動使用者會被踢 提供 plan 升級成 Team (5 台) 容忍 IP churn
License key 被破解 Offline mode 可被 patch 掉檢查 Online mode 可緩解；終極要法律 + 正版專屬功能
LibGit2Sharp Linux 容器相容性 某些 Alpine 容器需要額外 libgit2 系統包 Dockerfile 加 apk add libgit2
better-sqlite3 native build Windows 客戶端首次裝可能要 VS Build Tools 已記錄在 README；可預編 binaries
