1. 10 秒簡介

DB Migrator 是瀏覽器操作的資料庫匯出 / 匯入 + 專案備份還原工具，**商業授權**（試用 7 天 → 付費）。

  • 支援 5 種 DB：MySQL、PostgreSQL、SQL Server、SQLite、Supabase
  • 純 driver 實作，不需安裝 mysqldump 等 CLI
  • 有兩個對等實作版本：Node.js + Express、.NET 8 + ASP.NET Core，前端共用
  • 另有獨立的 License Server（Node + SQLite）負責授權 / 計費 / IP 紀錄
  • 拼圖式 plugin 架構：丟一個 .js / .cs 進 plugins/ 即生效

5. Adapter 介面契約

Node 介面（convention）

// adapters/<type>.js — 必須 export 這 5 個 + type
module.exports = {
  type: 'mysql',
  testConnection(conn)             → { ok, version, databases? }
  listTables(conn)                 → [{ name, rowEstimate }]
  dump(conn, options, outFile, onProgress)  → 寫檔
  restore(conn, sqlFilePath, onProgress)
  parseTableNamesFromDump(sqlFilePath)      → [tableName]
};

.NET 介面（強型別）

public interface IDatabaseAdapter {
    string Type { get; }
    Task<TestResult> TestConnectionAsync(DbConnectionInfo conn);
    Task<List<TableInfo>> ListTablesAsync(DbConnectionInfo conn);
    Task DumpAsync(DbConnectionInfo conn, ExportOptions options, string outFilePath, Action<string>? onProgress, CancellationToken ct);
    Task RestoreAsync(DbConnectionInfo conn, string sqlFilePath, Action<string>? onProgress, CancellationToken ct);
    List<string> ParseTableNamesFromDump(string sqlFilePath);
}

6. License 三模式

Mode觸發機制
offline預設讀本機 license.key（Ed25519）+ 32 天試用
onlineLICENSE_MODE=online + LICENSE_SERVER_URL=...登入 license server，每 30 秒 heartbeat，IP 換被踢
disabledLICENSE_MODE=disabled完全不檢查（dev only）

Gate middleware 邏輯

HTTP request /api/* │ ▼ ┌──────────────────┐ │ /api/license/* │── yes ──► next() (always) │ /api/modules? │ └──────────────────┘ │ no ▼ mode == disabled? ── yes ──► next() │ no ▼ mode == online? │ ├─ no token → 402 Not logged in ├─ kicked → 401 Session kicked ├─ status=expired → 402 License expired ├─ status=offline → 503 Cannot reach license server ├─ feature gate │ ├─ POST /api/export with N DBs > features.multi_db_count_max │ │ → 403 "您的方案最多可一次匯出 N 個" │ ├─ bulk_export=false && N>1 │ │ → 403 "試用版不支援多資料庫匯出" │ └─ /api/project/* && project_backup=false │ → 403 "試用版不支援專案備份" └─ next() │ ▼ (offline mode) status=expired? ── yes ──► 402 License required else next()

7. Plugin Host（Node 版）

lib/pluginHost.js — 掃 plugins/ 資料夾，自動載入 + hot reload。

支援的 plugin 形態

module.exports = {
  mount?:   '/api/foo',                    // Express route
  router?:  <express.Router>,
  adapter?: { type: 'foo', handler: { testConnection, ... } },
  ui?: {
    cards?: [{ type, title, sub, port? }],
    tabs?:  [{ id, label, html, scripts? }],
    scripts?: [...]
  },
  static?: 'public'   // 資料夾名，自動 serve 在 /plugins/static/<name>/
};

關鍵設計：route proxy（讓 hot reload 不用重新 mount）

// pluginHost 內部
const proxy = (req, res, next) => {
  const handler = currentPlugin.router;  // ← 隨時 swap
  return handler(req, res, next);
};
app.use(mount, proxy);   // 永遠掛這個 proxy

// 重新 require plugin 後：
currentPlugin.router = newRouterInstance;   // 直接換內部 handler

8. Job 系統

  • 匯出 / 匯入 / 專案備份都是長時間任務 → 走 job pattern

10. License Server 內部

SQLite schema（簡化）

users        id, email, password_hash, plan, max_devices,
             trial_started_at, expires_at, email_verified,
             ip_whitelist (JSON), free_until, stripe_customer_id

sessions     id (token), user_id, ip, user_agent, last_seen
event_log    id, user_id, ip, event, details (JSON), at
admin_sessions  id (cookie), user_id, ip, last_seen

核心邏輯：checkUserStatus()

1. free_until > now？ → return team-equivalent features (override)
2. plan == 'trial'?
     → 算 trial_started_at + duration_days
     → 過期 return 'expired'
     → 否則 return 'trial'
3. expires_at < now? → 'expired'
4. 否則 'licensed'

核心邏輯：heartbeat 踢人

POST /api/auth/heartbeat
1. session 存在？ → 不在 → 401 kicked
2. session.ip == 當前 IP？ → 不同 → 刪 session + log + 401 kicked
3. user 還在白名單？ → 不在 → 刪 session + 403
4. checkUserStatus() ok？ → 不 ok → 403
5. update last_seen → 200 + features

13. 已知踩坑

坑解
CSS [hidden] 被 .form-grid display:grid 蓋過style.css 開頭加 [hidden] { display: none !important; }
MSSQL Login failed 錯誤訊息空白從 SqlException.Errors[0].Message 撈內層
Empty port 字串 → .NET int 反序列化失敗 → ProblemDetails 沒 error 欄位 → 前端看到 undefined前端 port: portStr ? Number(portStr) : 0
SQL Server 連線：SSMS 用 Shared Memory 過、tedious 一定要 TCP/IPSQL Server Configuration Manager 啟用 TCP/IP + 開 SQL Browser
better-sqlite3 Windows 安裝失敗裝 VS Build Tools；不用 SQLite 可從 package.json 拿掉
LibGit2Sharp Linux 容器Dockerfile 加 apk add libgit2 或 apt install libgit2-dev
Supabase 用 PostgreSQL 卡片連 → SSL 拒絕必須用 Supabase 卡片（自動 ssl=true）
Hot reload 改前端 .js 不會自動 invalidate改 plugin 內的 .js 還是要 Ctrl+F5 重整瀏覽器
