三個元件可獨立部署：

  • License Server：你（owner）架在 VPS 或本機，所有客戶 app 連同一台
  • DB Migrator (Node) 跟 (.NET)：客戶端各自部署到自己機器跑
  • Target Databases：客戶自己的 DB，不一定在同一網段

請求流：登入 + heartbeat + 被踢

使用者 A 登入 (IP=1.1.1.1)
  Browser → DB Migrator → License Server
                          ├ 驗 email + password
                          ├ 檢查 plan / 試用未過期
                          ├ 檢查 IP 白名單
                          ├ 檢查 max_devices（超過 → 踢最舊）
                          └ 發 token
              ← 回 token + features

每 30 秒 heartbeat
  DB Migrator → License Server  POST /heartbeat (Bearer token)
                                ├ session 存在？
                                ├ IP 跟 session 紀錄一致？（不同就踢）
                                ├ plan 還沒過期？
                                └ 回最新 features
              ← 200 OK + features

使用者 A 在另一台 (IP=2.2.2.2) 也登入：
  另一台 → License Server (login)
                          └ 強制踢掉 IP=1.1.1.1 的 session
                            (DELETE FROM sessions...)
                            log 'kicked' event

  原本那台下次 heartbeat：
  DB Migrator → License Server  POST /heartbeat
                                └ session 不存在 → 401 kicked

  Browser 35 秒內也會 refresh banner
  → 顯示「🚫 您的帳號在另一台電腦使用」

請求流：試用版被擋下「多 DB 一次匯出」

1. 使用者勾 3 個 DB → 按「開始匯出」
2. Browser → DB Migrator
   POST /api/export   { databases: [db1, db2, db3] }

3. License middleware 攔截：
   ├ 取最新 license state (cache)
   ├ features.bulk_export === false ?
   ├ databases.length > features.multi_db_count_max ?
   └ 是 → return 403
       { error: "試用版不支援多資料庫一次匯出，請升級方案",
         feature: "bulk_export" }

4. Browser 收到 403 → 顯示升級提示
前端 UI 也會在 plan 改變時即時 disable 多選 checkbox（讓使用者根本選不到第 2 個）— 這是雙層防禦。

授權模式：offline ↔ online

模式觸發方式怎麼運作適用
offline 預設，或 LICENSE_MODE=offline 讀本機 license.key（Ed25519 簽章），無 license 時走 32 天試用（.trial 檔記時間） 單機 / 內網 / 不能連外
online LICENSE_MODE=online + LICENSE_SERVER_URL=... 登入 license server 拿 token，每 30 秒 heartbeat。IP 換掉、超過 max_devices、過期都會被踢 商用 / 多人 / 真的要管制
disabled LICENSE_MODE=disabled 完全沒有 gate，所有 /api/* 直接通過 開發 / 測試

Plugin 架構

Plugin 可以同時貢獻 4 種東西：

1. HTTP Route       module.exports.router  →  /api/<path>
2. DB Adapter       module.exports.adapter  →  在 Adapter Registry 註冊新 type
3. Frontend UI      module.exports.ui      →  cards / tabs / scripts
4. Static assets    module.exports.static  →  /plugins/static/<name>/...

Node 版會 watch plugins/ 資料夾 → 改檔案自動 hot reload
.NET 版要 rebuild（auto-discovery 在編譯時做）

失敗隔離（拼圖式）

  • 某個 adapter 載入失敗：只該卡片 disabled，其他 4 種照用
  • 某個 plugin 壞掉：只該 plugin 不可用，其他正常
  • 某個 route module 壞掉：該路徑回 503，其他路徑照跑
  • License server 連不到：app 進入「offline」狀態，已驗證的 session 暫時放行（不會直接掛掉）
  • Email server 連不到：register 仍會成功，驗證連結改在 console 印出（dev mode）
所有失敗狀態都可以從 GET /api/modules 看到 → 前端用此 disable 對應 UI。
