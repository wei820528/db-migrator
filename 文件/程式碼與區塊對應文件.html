加新 DB 類型（例如 Oracle、MongoDB）

Node 端

  1. node-express/adapters/oracle.js — 實作 5 個方法（testConnection / listTables / dump / restore / parseTableNamesFromDump），可以參考 mysql.js
  2. node-express/adapters/index.js 加 oracle: () => require('./oracle')
  3. node-express/package.json 加 driver 依賴（例："oracledb": "^6.x"）

.NET 端

  1. dotnet8/Adapters/OracleAdapter.cs 實作 IDatabaseAdapter
  2. dotnet8/Adapters/IDatabaseAdapter.cs 的 AdapterRegistry 建構式加 ["oracle"] = () => new OracleAdapter()
  3. dotnet8/DbMigrator.Web.csproj 加 NuGet PackageReference

前端

  1. 編輯 node-express/public/app.js：HOST_HINTS.oracle + TYPE_DEFAULTS.oracle
  2. 編輯 node-express/public/index.html 加卡片：<button class="card" data-type="oracle">...</button>
  3. 同步到 dotnet8/wwwroot/
完全不必動現有 4 種 adapter，是「拼圖式」加法。

加新 DB 卡片（不寫 adapter，靠 plugin）

不想改主程式：寫 plugin 即可。範例：node-express/plugins/oracle-plugin/index.js

module.exports = {
  adapter: { type: 'oracle', handler: { testConnection, ... } },
  ui: {
    cards: [{ type: 'oracle', title: 'Oracle', sub: 'Plugin DB', port: '1521' }],
  },
};

存檔 → 自動 hot reload → 卡片立刻出現在 UI。

加新 API route（內建）

  1. Node：node-express/routes/yourroute.js export 一個 Express Router
  2. Node：node-express/server.js 加 safeMount('/api/yourroute', './routes/yourroute', 'yourroute');
  3. .NET：dotnet8/Controllers/YourController.cs 加一個 [ApiController][Route("api/yourroute")] class — 自動 discover

寫一個 plugin（推薦取代「改主程式」）

Node — 三步

  1. 建 node-express/plugins/yourname/index.js
  2. export { mount, router, adapter?, ui?, static? } 任意組合
  3. 存檔 — hot reload 自動載入

.NET — 兩步

  1. 建 dotnet8/Plugins/YourController.cs 寫一個 controller
  2. 選用：dotnet8/Plugins/YourUiContributor.cs 實作 IPluginUiContributor 加 cards/tabs

詳見 plugins/README.md（兩個版本各一份）

加新前端 tab（不寫 plugin）

  1. node-express/public/index.html 在 .mode-switch 內加一顆 <button data-mode="yyy">...</button>
  2. 底下加一個 <section id="step-yyy" class="step mode-panel" hidden>...</section>
  3. node-express/public/app.js 在 .mode-switch button click handler 加對應的 $('#step-yyy').hidden = mode !== 'yyy';
  4. 同步到 dotnet8/wwwroot/

改 plan 限制（max_devices、features）

編輯 license-server/plans.js，重啟 license server 即可。例：

team: {
  max_devices: 10,           // 改成 10 台
  features: {
    bulk_export: true,
    multi_db_count_max: 20,  // 加大上限
    project_backup: true,
    max_export_mb: null,
  },
},
已存在的使用者要等下次 heartbeat 才會看到新限制（30 秒內）。

改試用天數

license-server/plans.js 的 trial.duration_days

trial: { ..., duration_days: 14 },   // 改成 14 天

已註冊的試用使用者：以「他的 trial_started_at + 新天數」計算，自動延長。

加新 feature flag（例如 max_table_count）

  1. license-server/plans.js：在每個 plan 的 features 加新欄位
  2. node-express/lib/license.js 的 gate() middleware：判斷 feature 後 403
  3. 前端 app.js 的 applyFeatureGates()：根據 feature 隱藏 / disable UI
  4. .NET 同上對應到 LicenseService + middleware

改 dump 格式（例如加 schema 清空指令）

每個 adapter 的 dump() 函式都自己負責 SQL 輸出。

MySQLnode-express/adapters/mysql.js / dotnet8/Adapters/MySqlAdapter.cs 的 dump
PostgreSQLpostgres.js / PostgresAdapter.cs
SQL Servermssql.js / MsSqlAdapter.cs
SQLitesqlite.js / SqliteAdapter.cs

切換 license mode

# 切到 online
$env:LICENSE_MODE = "online"
$env:LICENSE_SERVER_URL = "http://localhost:4000"
npm start

# 切回 offline
Remove-Item Env:LICENSE_MODE
npm start

# 完全停用（只供開發）
$env:LICENSE_MODE = "disabled"
npm start

負責切換的程式：node-express/lib/license.js

設定使用者 IP 白名單

用 admin CLI：

# （目前 CLI 沒這指令；改用直接呼叫 admin API）
curl -X PATCH http://localhost:4000/api/admin/users/<userId> \
  -H "Content-Type: application/json" \
  --cookie admin_session=... \
  -d '{"ip_whitelist": ["1.2.3.4", "10.0.0.0/8", "192.168.*"]}'

或用 Admin Web UI

在使用者編輯頁有 IP whitelist 欄位（逗號分隔）。

底層程式

license-server/lib/ip.js — 支援 plain IP、CIDR (10.0.0.0/8)、wildcard (192.168.*)

給某使用者「這個月免費」

Admin CLI（待加）或 Web UI：

# 設定 free_until 到月底
node admin-cli.js set-free --email user@example.com --until 2026-12-31

程式碼

license-server/server.js 的 checkUserStatus() 函式優先檢查 free_until，若有效就用 freeOverridePlan() 的 features（預設 = team plan）。

接 Stripe 付款

  1. 到 Stripe Dashboard 建立 Products + Prices，記下 price_xxx
  2. License Server 環境變數： 
    STRIPE_SECRET_KEY=sk_live_...
STRIPE_WEBHOOK_SECRET=whsec_...
STRIPE_PRICE_BASIC=price_xxx
STRIPE_PRICE_TEAM=price_yyy
STRIPE_PRICE_ENTERPRISE=price_zzz
  3. Stripe Dashboard 設 webhook → https://license.example.com/api/billing/webhook
  4. 程式碼：license-server/routes/stripe.js

換 email 服務商（SendGrid / Mailgun / Resend）

都支援 SMTP，只要改環境變數。例 SendGrid：

SMTP_HOST=smtp.sendgrid.net
SMTP_PORT=587
SMTP_USER=apikey
SMTP_PASS=<your sendgrid api key>
SMTP_FROM=no-reply@example.com

程式碼在 license-server/lib/email.js — 用 nodemailer，協定是標準 SMTP。
