三個檔案的分工

檔案負責什麼
public/index.html結構：把畫面切成 4 個 <section class="step">
public/style.css樣式：藍底 header、白色卡片、藍色按鈕、黑底 log
public/app.js互動：事件監聽、AJAX 呼叫、輪詢 job 狀態

HTML 結構（index.html）

<header>
  <h1>資料庫匯出 / 匯入</h1>
</header>

<main id="app">
  <section id="step-type" class="step active">       // 第 1 步：選 DB 類型
    <div class="cards">
      <button class="card" data-type="mysql">...
      <button class="card" data-type="postgres">...
      ...
  </section>

  <section id="step-conn" class="step">              // 第 2 步：連線設定
    <form id="conn-form">...                          // 一般 DB 用
    <form id="sqlite-form" hidden>...                  // SQLite 用
    <button id="btn-test">連線測試</button>
    <div class="mode-switch">...                       // 匯出/匯入切換
  </section>

  <section id="step-export" class="step mode-panel">  // 第 3a：匯出表單
  <section id="step-import" class="step mode-panel" hidden>  // 第 3b：匯入
</main>
核心機制：用 CSS class .step + .step.active 控制顯示。每個 section 預設 display: none，加上 .active 才會出現。 選了 DB 後 JS 會自動把後面兩個 section 加上 .active。

CSS 重要 class（style.css）

Class套在哪用途
.step每個大區塊白底圓角卡片，預設隱藏
.step.active—顯示該區塊
.cards類型卡片的容器4 欄 grid，可自動換行
.card單一類型卡白底邊框，hover 變藍邊
.card.selected—被選中：藍邊 + 淺藍底
.form-grid連線表單2 欄 grid，欄位上下排
.mode-switch匯出/匯入切換鈕容器頂部分隔線 + 灰色按鈕
.mode-switch .active被選中的切換鈕變成藍底白字
.log進度顯示區黑底淺灰字、等寬字體、含捲軸
.tables-list資料表勾選列表最高 280px，超過捲軸
.diff-table匯入對照表標準 HTML table，含底線
.exists-yes / .exists-no對照表的狀態文字已存在=橘字、不存在=綠字

JavaScript 主要事件（app.js）

1. 全域狀態物件

const state = {
  type: null,        // 'mysql' / 'postgres' / 'mssql' / 'sqlite'
  connection: null,  // 連線資訊（host/port/user/...）
  tables: [],        // 從 DB 拉回來的 table 清單
  uploadId: null,    // 匯入時記住已上傳檔的 ID
};

2. 卡片點擊事件

觸發：點任何一張 .card
動作：清除其他卡的 selected → 設目前 type → 顯示 step-conn 與 step-export → 切換 SQLite/一般表單 → 自動填預設 port

3. 連線測試按鈕

觸發：點 #btn-test
動作：fetch POST /api/connection/test → 成功則 loadTables() 抓資料表清單 → 失敗顯示紅色錯誤訊息

4. 匯出/匯入切換

觸發：點 .mode-switch button
動作：把 #step-export 與 #step-import 用 hidden 屬性互相切換

5. 開始匯出

觸發：點 #btn-export
動作：讀取 scope（全部/選擇）、勾選的 table、選項 (noData/noSchema) → fetch POST /api/export → 拿到 jobId → 呼叫 pollJob() 輪詢進度

6. 匯入兩步流程

步驟 1：點 #btn-inspect → 用 FormData 上傳檔案 → 回傳 diff 後產生對照表
步驟 2：點 #btn-import → fetch POST /api/import/run → 輪詢進度

7. pollJob() 輪詢函式

async function pollJob(id, logSel, resultSel, onDone) {
  while (true) {
    const job = await fetch(`/api/jobs/${id}`).then(x => x.json());
    $(logSel).textContent = (job.progress || []).map(p => p.line).join('\n');
    if (job.status === 'done')  { $(resultSel).innerHTML = onDone(job); return; }
    if (job.status === 'error') { ...錯誤訊息... return; }
    await new Promise(r => setTimeout(r, 800));  // 0.8 秒輪詢一次
  }
}
