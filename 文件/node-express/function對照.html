📄 server.js 入口檔

整個 app 的啟動點。建立 Express、掛載中介層與 4 個 API 路由、確保 tmp/ 目錄存在、啟動 HTTP server。沒有實質 function，全部是設定。

段落用途
express.json({ limit: '1mb' })解析 JSON body，最大 1MB（連線資訊夠用）
express.static('public')把 public/ 目錄當靜態檔 serve（前端 SPA）
app.use('/api/...')掛載 4 個 router
錯誤中介層未捕捉的錯誤統一回 500 + JSON
app.listen(PORT)預設 port 3000，可用 process.env.PORT 覆寫

📄 routes/connection.js 連線測試 + 列表

Function / 路由方法說明請求回應
POST /testPOST 測試 DB 連線，回 server 版本字串 { type, host, port, user, password, database } { ok: true, version: "8.0.36..." }
失敗回 { ok: false, error }
POST /tablesPOST 列出 DB 內所有 table（含粗略列數） 同上 { tables: [{ name, rowEstimate }, ...] }
兩條路由都呼叫 getAdapter(type) 拿到對應 adapter，再呼叫 adapter 內的方法。

📄 routes/export.js 匯出主流程

Function / 路由方法說明
POST /POST 啟動匯出 job。
1. 用 jobs.create('export') 拿 jobId
2. 建立 tmp/{jobId}/ 資料夾
3. 立即回 jobId 給前端（不等匯出完成）
4. 背景跑 adapter.dump(...)，邊跑邊用 jobs.append() 寫進度
5. 完成後把 status 設成 done 並寫 downloadUrl
GET /:id/fileGET 把已完成 job 的 SQL 檔送回客戶端下載。
找出 tmp/{id}/ 內第一個 .sql 檔，用 res.download() 串流回傳。
匯出檔放在 tmp/{jobId}/{database}.sql，目前沒有自動清理，正式環境要加排程。

📄 routes/import.js 匯入主流程

Function / 路由方法說明
POST /inspectPOST (multipart) 第一階段：上傳 SQL 檔並做檢查。
1. 用 multer 接 multipart 上傳檔（限 1GB）
2. 暫存到 tmp/uploads/{uploadId}
3. 呼叫 adapter.parseTableNamesFromDump() 從檔案抓 table 名稱
4. 呼叫 adapter.listTables() 抓目標 DB 已存在的 table
5. 做 diff 回傳：每個檔內 table 是否已存在於目標
POST /runPOST 第二階段：實際執行匯入。
1. 依 uploadId 找到剛剛上傳的檔
2. 建 import job 並回 jobId
3. 背景跑 adapter.restore()
4. 完成後刪掉上傳的暫存檔

📄 routes/jobs.js 進度查詢

Function / 路由方法說明
GET /:idGET 回傳整個 job 物件：{ id, kind, status, progress: [], result, error, createdAt }
前端每 0.8 秒 polling 一次直到 status 變成 done 或 error。

📄 lib/jobs.js 記憶體型 Job Tracker

Function參數用途
create(kind)kind: 'export' 或 'import'產生新 job、給 UUID、放進 Map、回傳 job 物件
get(id)id: jobId從 Map 拿 job；找不到回 null
append(id, line)line: 進度文字把一行進度推進 progress 陣列；超過 200 筆會自動丟掉最舊的
setStatus(id, status, patch)status: 新狀態
patch: 要合進去的欄位（result/error）		更新 status 並 merge 額外欄位
✨ 自動清理機制：用 setInterval 每 10 分鐘掃一次，把建立超過 1 小時的 job 刪掉，避免記憶體膨脹。
⚠️ 注意：jobs 存在 process 記憶體裡，重啟服務後全部清光。若要保存歷史紀錄要改用 Redis 或 SQLite。

📄 adapters/_shared.js 共用工具

Function用途
escapeIdent(name, q)幫 column / table 名加跳脫符號（MySQL 用 `、PG 用 "、MSSQL 用 [）
escapeStringSql(s)把字串裡的 ' 加倍轉成 SQL 字面值（ANSI 風格）
formatValueGeneric(v, opts)萬用型別轉 SQL：null/數字/布林/Buffer/Date/物件 各自處理
splitSqlStatements(sql, q)把多句 SQL 切成單句陣列。會正確處理 --、/* */ 注釋與字串/識別字內的分號
parseTableNamesFromDumpGeneric(text, q)用 regex 從 dump 文字中抓出所有 CREATE TABLE xxx 的 table 名

📄 adapters/mysql.js MySQL adapter

Function用途
buildConnConfig(c, extra)把 user 的 connection 物件轉成 mysql2 的 config（含 port 預設 3306、charset utf8mb4、timeout 8 秒）
testConnection(conn)建連線跑 SELECT VERSION()，回 { ok, version }
listTables(conn)查 information_schema.TABLES，回 [{ name, rowEstimate }]
escapeIdent(name)用反引號跳脫 identifier
formatValue(v)把任意值轉成 MySQL 可吃的 SQL 字面值；二進位用 0x...
dumpTableSchema(conn, table, stream)用 SHOW CREATE TABLE 拿 DDL 直接寫進 stream（含 DROP TABLE IF EXISTS）
dumpTableData(rawConn, table, stream, onProgress)用 query stream 一筆一筆讀資料，每 500 筆或 0.5MB 就 flush 一個 multi-row INSERT
dump(conn, options, outFilePath, onProgress)主要匯出進入點。建立 file stream、寫 header、決定哪些 table 要 dump、逐表呼叫 schema/data 兩個 helper
restore(conn, sqlFilePath, onProgress)把整份 SQL 一次餵給 connection.query()（要開 multipleStatements: true）
parseTableNamesFromDump(sqlFilePath)regex 抓 CREATE TABLE `xxx` 內的 xxx

匯出資料的批次邏輯

const MAX_BATCH = 500;          // 每 500 筆 flush 一次
const MAX_BYTES = 512 * 1024;   // 或累積 0.5 MB 也 flush

// 每收到一筆 row：
buffer.push('  (val1, val2, ...)');
if (buffer.length >= MAX_BATCH || bufferBytes >= MAX_BYTES) flush();

function flush() {
  stream.write(`INSERT INTO ... VALUES\n` + buffer.join(',\n') + ';\n');
}

📄 adapters/postgres.js PostgreSQL adapter

Function用途
buildClient(c)建 pg.Client（預設 port 5432）
testConnection / listTables同 MySQL 概念，差別在用 PG 的 information_schema 查詢，回傳 table 名是 schema.table 格式
getTableDDL(c, schema, table)自己組 DDL（PG 沒有 SHOW CREATE TABLE）：查 columns、PK，組合成 CREATE TABLE
dumpTableData(...)用 pg-query-stream 串流讀資料（避免一次撈進記憶體）
dump(...)主入口；多了 schema.table 拆分邏輯
restore(...)用 splitSqlStatements 切句後逐句送（PG 不支援 multipleStatements）

📄 adapters/mssql.js SQL Server adapter

Function用途
buildConfig(c)建 mssql 套件的 config（含 trustServerCertificate: true）
bracket(n)用 [ ] 跳脫 identifier（T-SQL 風格）
fmt(v)包裝 formatValueGeneric：字串用 N'...'、二進位 0x...、布林用 0/1
getTableDDL(pool, schema, table)查 sys.columns、sys.types、sys.indexes 組 DDL，含 IDENTITY 與 default 處理
dumpTableData(...)用 pool.request().stream = true 串流
splitMsSqlBatches(text)MSSQL 特有：按 GO 分批（sqlcmd 指令）
restore(...)逐批送進 request().batch()

📄 adapters/sqlite.js SQLite adapter

Function用途
pickPath(c)從 c.path / c.database / c.host 三選一拿檔案路徑
open(c, readonly)呼叫 better-sqlite3 打開 DB；read 用 readonly、restore 用 read-write
testConnection / listTables查 sqlite_master
dump(...)直接讀 sqlite_master.sql 拿原始 DDL（SQLite 原生就有存）；資料用 iterator；SQLite 是唯一會輸出 index 的 adapter
restore(...)用 db.exec() 在 transaction 內逐句執行；自動 ROLLBACK 失敗的

所有 adapter 都實作的 5 個方法

這是 adapter 的「介面合約」。新加任何 DB 都要實作這 5 個。

方法簽名用途
testConnection(conn) => { ok, version, error? }確認可連線並回版本
listTables(conn) => [{ name, rowEstimate }]給前端顯示
dump(conn, options, outFilePath, onProgress) => void把 DB 寫成 .sql 檔
restore(conn, sqlFilePath, onProgress) => void把 .sql 灌進 DB
parseTableNamesFromDump(sqlFilePath) => [string]從 dump 抓 table 名（給 inspect 用）
