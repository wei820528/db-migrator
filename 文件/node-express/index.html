專案概觀

這是一個用 Node.js 18+ / Express 寫成的網頁工具，功能是把 MySQL、PostgreSQL、SQL Server、SQLite 四種資料庫做匯出 (export) 與匯入 (import)。
和傳統 mysqldump、pg_dump、sqlcmd 工具不同，這個版本是純 driver 實作，不需要在主機安裝任何 CLI 工具，連線資訊填一填就能用。

啟動指令： 
cd F:\匯出資料庫的bat\node-express
npm install
npm start        # 服務在 http://localhost:3000
第一次 npm install 時 better-sqlite3 會做 native build；Windows 需要 Visual Studio Build Tools。

系統運作流程

步驟使用者動作背後執行
1選擇 DB 類型前端 app.js 設定 state.type
2填連線資訊並按「連線測試」POST /api/connection/test → adapter.testConnection()
3測試成功後自動拉資料表清單POST /api/connection/tables → adapter.listTables()
4a按「開始匯出」POST /api/export → 建立 job → 背景跑 adapter.dump() → 寫進 tmp/{jobId}/xxx.sql
5a前端每 0.8 秒輪詢進度GET /api/jobs/:id → 回 progress 陣列
6a完成後點下載連結GET /api/export/:id/file → 串流送回 SQL 檔
4b選 SQL 檔按「檢查內容」POST /api/import/inspect → 解析 dump 的 table 名稱 → 比對目標 DB
5b按「執行匯入」POST /api/import/run → adapter.restore() → 逐句送進目標 DB

已知限制

純 driver 版相對 native dump 工具會少這些：
  • ❌ 外鍵約束（CREATE TABLE 內不會包含）
  • ⚠️ 次要索引（SQLite 有，其他無）
  • ❌ Triggers / Stored procedures / Functions / Views
  • ❌ PostgreSQL 的 Sequences、MySQL 的 Events
  • ❌ 沒有 auth — 不要直接放上公網
一般 application DB 用前兩項就夠，這些限制請在交接後依需求補。
