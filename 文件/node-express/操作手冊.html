🚀 第一次啟動

1確認 Node.js 版本

需要 Node.js 18 以上版本。在 PowerShell 或 cmd 執行：

node --version

若版本低於 v18.0.0，請至 nodejs.org 下載安裝 LTS 版。

2安裝套件（第一次才需要）

cd F:\匯出資料庫的bat\node-express
npm install
⚠️ 重要：第一次跑 npm install 時 better-sqlite3 會做 native build。
Windows 上若失敗，請先安裝 Visual Studio Build Tools（含 C++ 桌面開發工作負載）。
若不需要用 SQLite，可以從 package.json 拿掉 better-sqlite3 再 install。

3啟動服務

npm start

看到下面這行表示成功：

DB migrator listening on http://localhost:3000

用瀏覽器打開 http://localhost:3000 即可開始使用。

💡 開發模式可用 npm run dev，會在程式修改後自動重啟。

2. 連線設定 mysql

✓ 成功，8.0.36-MySQL Community Server
▲ 第 2 步：填入連線資訊後按「連線測試」，成功會顯示綠色版本訊息
選 SQLite 時表單會變不一樣：只剩一個「SQLite 檔案路徑」欄位，例如 C:\data\app.db。
常見錯誤：
  • ECONNREFUSED 127.0.0.1:3306 → DB 服務沒啟動或 port 不對
  • Access denied for user → 帳號密碼錯誤
  • Unknown database 'xxx' → database 名稱錯誤

Dumping 5 table(s) > users users: 5000 rows... users: 10000 rows... users: 12834 rows done > orders orders: 5000 rows... orders: 10000 rows... ... Done
📥 下載 SQL 檔
▲ 第 3a 步：匯出進度即時顯示在黑色 log 區，完成後出現下載連結
勾選說明：
  • 只匯出結構 = 只產生 CREATE TABLE，不包資料
  • 只匯出資料 = 只產生 INSERT INTO，假設目標 DB 已有相同結構
  • 兩個都不勾 = 完整匯出（結構 + 資料）

⚠️ 注意：

  • 正式環境建議先做備份再執行

🛑 停止服務

在跑 npm start 的 PowerShell 視窗按 Ctrl + C 即可停止。
tmp/ 內的暫存檔不會自動清理，可以定期手動清空（或設排程）。

🆘 疑難排解

症狀可能原因 / 解法
Cannot find module 'express'沒執行 npm install
port 3000 被佔用改用其他 port：set PORT=4000 && npm start
匯出後檔案打不開用記事本打開檢查格式，若亂碼是編碼問題（應為 UTF-8）
匯入時 timeout檔案太大；目前的限制是 1GB；超過要分批匯入
