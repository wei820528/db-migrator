⚡ 快速啟動

Node.js 版（port 3000）

cd F:\匯出資料庫的bat\node-express
npm install
npm start

.NET 8 版（port 3001）

cd F:\匯出資料庫的bat\dotnet8
dotnet restore
dotnet run

🎯 該選哪個版本繼續開發？

情境建議
已有 Node.js / npm 生態用 node-express，套件豐富、開發快
公司是 .NET shop / 想單一 .exe 部署用 dotnet8，可發佈成 self-contained exe
要長期維護、強型別、企業環境用 dotnet8，C# 型別系統與工具鏈完整
輕量、要常改 UI / 加功能用 node-express，hot reload 體驗較好
