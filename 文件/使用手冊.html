1. 系統需求

  • 一台 Windows / macOS / Linux 電腦
  • 瀏覽器：Chrome / Edge / Firefox 最新版
  • 網路連線（用於登入授權伺服器）
  • 要匯出 / 匯入的資料庫帳號密碼
本工具不需要安裝資料庫 CLI（mysqldump / pg_dump 等），全部透過 driver 直接連。

步驟 3 ─ 收驗證信

5. 匯出資料庫

步驟

  1. 點要的 DB 卡片（例 MySQL）
  2. 填 Host、Port、User、Password
  3. 按「連線測試」

  5. 選範圍 / 進階選項

  4. 選 SQL 檔，按「檢查內容」

問題回答
換電腦了，原本那台還能用嗎？不行。同帳號同時只能 1 台（Team 5 台）。新電腦登入時，原本那台 30 秒內會被踢，看到上面那個畫面。
我家網路 IP 一直變會被一直踢。請聯繫升級到 Team 方案（同時 5 台），或設定 IP 白名單。
忘記密碼目前需聯繫客服手動重設（自助 reset 功能 roadmap 上）。
匯出哪些 DBMySQL、MariaDB、PostgreSQL、SQL Server (含 SQLEXPRESS)、SQLite、Supabase
匯出檔包含敏感資料嗎包含 DB 裡所有資料，請保管好下載的檔案。
Supabase 連不上 / SSL 錯請點「Supabase」卡片（自動啟用 SSL），不是「PostgreSQL」卡片。
