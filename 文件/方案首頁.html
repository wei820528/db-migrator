⚡ 快速啟動三件元件

License server 必須先起，兩個 DB Migrator 才能用 online mode。

# ① License Server (port 4000) cd F:\匯出資料庫的bat\license-server npm install && npm start # ② DB Migrator Node (port 3000) cd F:\匯出資料庫的bat\node-express $env:LICENSE_MODE="online"; $env:LICENSE_SERVER_URL="http://localhost:4000" npm install && npm start # ③ DB Migrator .NET (port 3001) cd F:\匯出資料庫的bat\dotnet8 $env:LICENSE_MODE="online"; $env:LICENSE_SERVER_URL="http://localhost:4000" dotnet restore && dotnet run
